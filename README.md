# hoofam docs

hoofam 앱의 지원 페이지와 개인정보 처리방침. GitHub Pages(`main` 브랜치 루트)로 `https://hoofam.github.io/docs/`에 게시한다.

앱마다 폴더 하나에 `support.md`와 `privacy.md`를 둔다. 확장자 없이 열린다.

| 앱 | 지원 | 개인정보 처리방침 |
|---|---|---|
| crabar | https://hoofam.github.io/docs/crabar/support | https://hoofam.github.io/docs/crabar/privacy |

새 앱을 넣을 때는 `crabar/`를 복사해 내용을 고치고, `index.md`와 위 표에 링크를 더한다.
